# Routine-Zielwerte pro messbarem Habit

Jede Routine kann pro messbarem Habit einen **eigenen Zielwert** speichern (z. B. 500 ml von 3000 ml Tagesziel). Beim Abarbeiten wird in `habit.incrementValue`-Schritten erhöht, bis der Routine-Zielwert erreicht ist — dann gilt das Habit in dieser Routine als erledigt (das Tagesziel bleibt unangetastet).

## 1. Modell: `HabitRoutine` (additiv, keine Migration)

**Datei:** `ThriveWood/Data/Models/HabitRoutineDomain.swift`

Neue Property (Inline-Default, gemäß `HOW_TO_MODIFY_SWIFT_DATA.md`):

```swift
/// Optionaler Routine-Zielwert pro messbarem Habit (UUID -> Wert).
/// Fehlt der Eintrag oder ist 0, gilt das Tagesziel des Habits.
var habitTargets: [UUID: Double] = [:]
```

- SwiftData speichert `[UUID: Double]` als transformable/JSON automatisch.
- `habitIDs: [UUID]` bleibt die geordnete Quell-Wahrheit — `habitTargets` ist reine Zusatz-Map.
- Keine Änderung an `SharedModelContainer.swift` (gleiche `HabitRoutine.self`-Registrierung).
- Beim Auto-Cleanup (`removeHabitFromAllRoutines`) zusätzlich `habitTargets[habitID]` entfernen (Repositories.swift Zeile ~741) — analog zu `habitIDs.removeAll`.

## 2. Run-Screen: `RoutineRunView.swift`

**VM `RoutineRunViewModel`:**

- `routineTarget(for habit: Habit) -> Double` — `routine.habitTargets[habit.id]` falls > 0, sonst `habit.targetValue`.
- `refreshStatus()` umbauen: statt `currentProgress` direkt zu verwenden, pro Habit:
  - `let daily = try? env.habitService.currentProgress(habit)` (liefert den Tages-`value`).
  - `let value = min(daily.value, routineTarget)` — für die Routine relevant nur bis zum Routine-Ziel.
  - `let target = routineTarget(habit)`
  - `let p = target > 0 ? min(1.0, value / target) : 0`
  - `progress[habit.id] = (value: value, target: target, progress: p)`
  - `if p >= 1.0 { completedIDs.insert(habit.id) }`
- `increment(_:)`: unverändert — ruft `env.habitService.increment(habit)` (defaultet auf `habit.incrementValue`). VM prüft danach via `refreshStatus` erneut, ob Routine-Ziel erreicht → Land in `completedIDs`.
  - Optionaler UX-Nicety: wenn der nächste Schritt über den Routine-Zielwert hinausschießen würde, auf genau den Routine-Zielwert clampen (einmalig `setValue(habit, value: routineTarget)`). Entweder integriert oder weggelassen — siehe "Offene Entscheidung" unten; ich implementiere es **mit** Clamping, damit z. B. bei 250ml-Schritten und 500ml-Ziel exakt 500ml ankommen (kein Überschuss).
- `overallProgress` / `doneCount` / `allDone` basieren auf `completedIDs` → unverändert, automatisch korrekt, weil `completedIDs` jetzt gegen den Routine-Zielwert prüft.

**View `RoutineRunView`:** keine Änderung nötig. `BentoHabitRowView` bekommt den routine-angepassten `progress`-Tupel (Routine-Ziel als `.target`, recomputeter Bruch als `.progress`) und rendert korrekt — die Row liest weder `habit.targetValue` noch `habit.incrementValue` direkt (verifiziert).

## 3. Editor: `RoutineEditorSheet.swift`

Neuer State pro angewähltem messbarem Habit:

```swift
@State private var habitTargets: [UUID: Double] = [:]
```

- `hydrate()`: beim Bearbeiten `habitTargets = routine.habitTargets` übernehmen.
- `habitPickerRow(_ habit:)`: wenn `habit.isMeasurable && selectedHabitIDs.contains(habit.id)`, unter der Zeile ein aufklappbares Feld:
  - Label "Ziel in dieser Routine" + Unit (`habit.unitLabel`).
  - Vorschlag beim ersten Auswählen: `habit.targetValue` (Tagesziel) — nur initial, danach nicht überschreiben.
  - `BentoTextField`-Zahlenfeld oder Stepper (± `habit.incrementValue`), bequemer ein Tippfeld mit Keyboard `.decimalPad`.
- Beim Abwählen: `habitTargets.removeValue(forKey: habit.id)`.
- `save()`: `habitTargets` in das `HabitRoutine`-Objekt schreiben bzw. an `HabitRoutine(habitTargets:)` weiterreichen. Konstruktor-Erweiterung: Default `[:]`.

Default-Verhalten: Routine-Ziel == Tagesziel, wenn der Nutzer nichts ändert (Kompatibilität mit bestehenden Routinen, die keine `habitTargets` haben).

## 4. Repo/Protokoll

- `HabitRoutineRepository`-Protokoll (Helpers/Protocols.swift): **keine** neuen Methoden — `create`/`update` persistieren das ganze Objekt inkl. `habitTargets`.
- `SwiftDataHabitRoutineRepository.removeHabitFromAllRoutines` (Repositories.swift ~739): zusätzlich `routine.habitTargets[habitID] = nil` pro Routine.

## Randbedingungen / Verträglichkeit

- **Additiv & migrationsfrei:** neue optionale-default Property → Lightweight Migration, kein Plan nötig (HOW_TO-konform).
- **Bestehende Routinen:** `habitTargets` ist `[:]` → Verhalten identisch zu heute (Tagesziel gilt).
- **Auto-Cleanup** weiterhin sauber (archivierte/gelöschte Habits inkl. ihrer Ziele entfernt).
- **Tagesfortschritt unangetastet:** die Routine ändert nur, *wie viel* für "in dieser Routine erledigt" zählt, nicht das Tagesziel des Habits oder die Punkte-Logik.
